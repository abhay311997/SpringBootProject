1. Initialise git repo

PS C:\github> git init 
	Initialized empty Git repository in C:/github/.git/
	
	
Created a local Repo

2. Add a remote repo to local
create a repo at github online

PS C:\github> git remote add origin https://github.com/abhay311997/github.git
	
3. i) Make any local changes, that will show in 
PS C:\github> git status   
On branch main
Your branch is up to date with 'origin/main'.

  (use "git add <file>..." to include in what will be committed)
        Git-Learning.txt
        WindowVsTerminalCmd.txt
        desktop.ini
nothing added to commit but untracked files present (use "git add" to track)

ii) add that changed file in staged changes
PS C:\github> git add .\Git-Learning.txt

iii) PS C:\github> git status
On branch main
Your branch is up to date with 'origin/main'.

Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
        new file:   Git-Learning.txt

Untracked files:
  (use "git add <file>..." to include in what will be committed)
        WindowVsTerminalCmd.txt
        desktop.ini
		
iv) commit the staged file to remote branch
PS C:\github> git commit -m "study"
[main a6b78da] study

 create mode 100644 Git-Learning.txt

4). Create a new branch and switch 
PS C:\github> git checkout -b "Readme"
Switched to a new branch 'Readme'

5). Push local commits from Readme directly into the remote main branch without switching branches locally:
> git push origin Readme:main

6). Push all local branches that exist on your machine to the remote:
> git push origin --all
