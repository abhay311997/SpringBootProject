java-basics:- 
1) To run Main File first gradle build then Run
PS C:\SpringBoot\Project\java-basics> ./gradlew build

2) To run via build jar, after a change add this in Kotlin DSL (build.gradle.kts)
to add in jar MANIFEST

tasks.jar {
    manifest {
        attributes["Main-Class"] = "com.learning.Main" // Replace with your fully-qualified class name
    }
}

then run 
PS C:\SpringBoot\Project\java-basics> ./gradlew build
then 
PS C:\SpringBoot\Project\java-basics> java -jar build\libs\java-basics-1.0-SNAPSHOT.jar


3) Make a Client
hit a http request to server and get response 

- add below in in (build.gradle.kts)'s dependencies
	implementation("com.squareup.okhttp3:okhttp:5.5.0")
- add below in (build.gradle.kts)'s tasks.jar to make build jar a fat jar , fat jar mean in our jar dependencies classes will also get added.
    from(configurations.runtimeClasspath.get().map { if (it.isDirectory) it else zipTree(it) })
- add below in (build.gradle.kts)'s tasks.jar to exclude duplicate dependencies classes 
	duplicateStrategy = DuplicatesStrategy.EXCLUDE
```
tasks.jar {
    manifest {
        attributes["Main-Class"] = "com.learning.Main" 
    }
    duplicatesStrategy = DuplicatesStrategy.EXCLUDE
    from(configurations.runtimeClasspath.get().map { if (it.isDirectory) it else zipTree(it) })

}
```
